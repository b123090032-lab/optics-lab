# 🔬 光的干涉與繞射實驗室（Slit Lab）

👉 **線上玩：https://b123090032-lab.github.io/optics-lab/**

生成式 AI 課程第五週作業（補交）：用 Vibe Coding 做出一個互動網頁。

- 拉參數（波長、縫數、縫寬、縫距、螢幕距離）即時看單狹縫 / 雙狹縫 / 光柵條紋
- 強度曲線＋量測游標、鎖定曲線比較、波前動畫
- 挑戰模式：從條紋反推波長，計分、存最高分
- 自動儲存、分享連結、下載 PNG，手機也能用

- `index.html`：整個網頁（HTML + CSS + JS 都在這一個檔案）
